# Portafolio · Jesús David Mercado

Portafolio en React (Vite) con panel administrativo para gestionar experiencias profesionales (CRUD).

## Cómo ejecutarlo

Primera vez:
```
npm install
copy .env.example .env
```

Terminal 1 (API):
```
npm run api
```

Terminal 2 (web):
```
npm run dev
```

La web queda en http://localhost:5173
